`tools/get-godot.sh` downloads into `~/.cache/full-theta/godot/<version>` (override with `GODOT_CACHE`), verifies each file and prints the binary path; `--with-templates` also installs the export templates. A tampered checksum file (`GODOT_SHA512=<file>`) makes it exit 1 with "checksum mismatch". From a clean cache the editor binary downloads and verifies in about 16 s, and `--version` prints `4.7.2.stable.official.ed1daf0bf`.

Untyped declarations are errors (`debug/gdscript/warnings/untyped_declaration=2`): a probe script with an untyped `var` and function fails `--check-only` with "Warning treated as error".
