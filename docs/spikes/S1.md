# S1: clean-clone import, tests and exports

Run on fugaku (i7-11800H, 16 threads, no GPU used), 2026-10-19, Godot 4.7.2-stable, gdUnit4 6.2.2 (FT-GEN-012, R1).

## Method

`git clone` of the branch into a scratch directory, overlaid with the uncommitted branch work (no `.godot/`, no `build/`), then from the CLI only:

| Step | Command | Result |
|---|---|---|
| Cold import (no `.godot/`) | `godot --headless --path . --import` | exit 0, 3.5 s (two runs: 3.49 s, 3.49 s) |
| Warm import | same, again | exit 0, 3.2 s (3.21 s, 3.21 s) |
| gdUnit4 | `tools/gate.sh l1` | 1 test, 0 failures, JUnit XML at `build/reports/report_1/results.xml` |
| A failing test | gdUnit4 on a probe suite asserting `1 == 2` | exit 100 |
| Linux and Windows exports, Linux smoke run | `tools/gate.sh l6` | pass, 13 s with templates installed |
| macOS export | `godot --headless --path . --export-release macOS` | succeeds with `import_etc2_astc=true`, now set in `project.godot` (below) |

The import times include editor start-up, so the project's own import is a fraction of a second at this size. The editor settings in `~/.local/share/godot` were already present.

The same `tools/gate.sh ci` (import, L0, L1) also ran in a bare `ubuntu:24.04` container with only curl, unzip, git and uv installed: Godot runs headless there with no extra libraries.

## Exports

`export_presets.cfg` has Linux, Windows and macOS presets, all writing under `build/` (gitignored) and excluding `tests/`, `tools/`, `docs/` and `addons/gdUnit4/`. Linux and Windows embed the PCK.

- **Linux** (`build/linux/full-theta.x86_64`, 74 MB): exports, and `timeout 5 build/linux/full-theta.x86_64 --headless -- --server` prints the server stub line and exits 0. The stub quits at once, so the 5 s is an upper bound until the server loops.
- **Windows** (`build/windows/full-theta.exe`, 109 MB): cross-builds on Linux with `application/modify_resources=false` (no rcedit or Wine needed). Running it is the owner's step (T065).
- **macOS**: without the setting below the preset fails with "Cannot export for universal or arm64 if ETC2 ASTC texture format is disabled". The templates ship only a universal binary (`godot_macos_release.x86_64` is missing, so an x86_64-only preset fails too). With `rendering/textures/vram_compression/import_etc2_astc=true` (now committed in `project.godot`) the export succeeds in 10 s: an unsigned, un-notarised `Full Theta.app` in a 60 MB zip. It wasn't run (no Mac); it needs signing and notarisation before players can open it without a Gatekeeper override (FT-ARC-017 risk).

## Export templates and CI

The templates archive is 1.28 GB; `tools/get-godot.sh --with-templates` downloaded, verified and unpacked it in 222 s on fugaku, and the unpacked templates take 2.0 GB. Caching both in Actions would hold about 3.3 GB of the repo's 10 GB cache and still cost a large restore on every run, so `gate.sh ci` runs only L0 and L1, and L6 runs on fugaku, as FT-TST-005 and research/tech §7.3 plan.
